## `/version` 命令

### `/version` - CHAT

**完整格式**：`/version`

**所需权限组**：无；所有用户可用（ANY）。

读取当前安装目录的 `metadata.yaml` 中的版本号，以 `KakoBot v1.3.2` 这样的格式回复文字。返回的是实际安装版本，不读取远端版本，也不以 Dev 标题或最新日志条目猜测版本。

不接受任何参数；私聊、群聊所有用户都能使用。版本文件无法读取或版本格式无效时返回明确错误。

```text
/version
```
