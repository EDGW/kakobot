# 个人 AI 对话命令目录

[命令目录](../README.md) · [普通帮助](help.md) · [Super 管理](super.md)

个人 `/discuss` 仅用于私聊，与群 `/group-discuss` 分别管理入口、Key、历史、用户预算和工具权限。默认对全局 Super 开放，其他用户须由 Super 单独开启；每位用户都须配置自己的 DeepSeek Key。

- [帮助、Key 与会话](help.md)
- [个人配置与常用设置](configuration.md)
- [工具与业务命令](tools.md)
- [全局 Super 管理个人用户](super.md)

帮助使用预生成 JPEG：`/discuss help`、`/help discuss`；管理帮助使用 `/super discuss help`、`/super help discuss`。个人文档与图片均位于 discuss 子目录，群聊说明另见 [群 AI 对话](../group-discuss/README.md)。
