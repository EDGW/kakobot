本组涉及以下身份组：

- 无；所有用户可用。

## `/help` 命令

### `/help` - CHAT

**完整格式**：`/help [命令]`

**所需权限组**：无；所有用户可用。

按当前会话位置和有效身份组显示可使用的命令，省略命令名时列出全部普通命令。指定命令组可查看该组，指定子命令可只看其语法。

命令名可带或不带开头的斜线；无匹配或无权限时返回“没有可用的对应命令”。Super 管理命令使用 `/super help` 查看。

```text
/help
/help ddl
/help ddl add-strict
```

## `hello` 命令

### `hello` - GROUP

**完整格式**：`你好`

**所需权限组**：无；所有用户可用。

当消息正文只有“你好”时，回复“好牛魔呢”。带有其他正文时不触发此问候；此入口仅在群聊提供。
