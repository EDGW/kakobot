# 帮助与问候 命令组

[命令目录](README.md) · [Super 管理](super/README.md)

本组涉及以下身份组（不新增身份组）：

- 无；所有用户可用。

## `/help` 命令

### `/help` - CHAT

**完整格式**：`/help [命令]`

**所需权限组**：无；所有用户可用。

显示可用命令及资源限制。

### `/help` - GROUP

**完整格式**：`/help [命令]`

**所需权限组**：无；所有用户可用。

须先真实 @机器人。显示可用命令及资源限制。

## `hello` 命令

### `hello` - GROUP

**完整格式**：`你好`

**所需权限组**：无；所有用户可用。

须先真实 @机器人。真实@机器人且没有其他正文时问候。

## 使用规则与示例

群内必须真实 @机器人；文本中手打“@机器人”不算。仅真实 @机器人并说“你好”时回复“好牛魔呢”。

`/help [命令]` 根据当前身份组和会话位置展示可用语法，例如 `/help ddl`、`/help ddl add-strict`；Super 专用说明见 `/super help`。

超过15行的文字输出会放入合并聊天记录，图片直接发送。
