# DDL 命令组

[命令目录](README.md) · [Super 管理](super/README.md)

本组涉及以下身份组：

- `ddl`：个人创建、默认提醒及清空。
- `admin`：群创建、清空及跨群清空。
- `group.ddl`：当前群创建。
- `group.admin`：当前群清空，并继承 group.ddl。

## `/ddl add` 命令

### `/ddl add` - CHAT

**完整格式**：`/ddl add 内容`

**所需权限组**：`ddl`

将 `内容` 交给 AI，提取并创建一条 DDL。正文最多200字，可包含标题、截止日期、提前提醒要求和是否到期通知；缺少标题时由 AI 生成，作业标题应体现课程。不会额外读取群上下文。

任务归属本人且只通知本人，不能借此创建其他用户或源群的任务。

未指定提前提醒时，默认提前30分钟、3小时、12小时、1天、1天12小时。AI 默认追加到期提醒，明确要求“到期不要再提醒”时取消到期节点。

时间按北京时间解释，截止时间必须在未来。每项任务为一次性提醒，最多20个提醒时间；已经过去的提醒节点忽略。保存成功后发送确认和当前会话的 DDL 卡片。定时提醒也发送红色图片卡片；群聊会同时 @ 通知对象。

请求真正提交模型后先回复“已提交模型，正在处理，请稍候。”；提取或校验失败时不会创建任务。

```text
/ddl add 明天18点提交物理作业，提前3小时和30分钟提醒，到期不要再提醒
```

### `/ddl add` - GROUP

**完整格式**：`/ddl add 内容`

**所需权限组**：`admin` 或 `group.ddl`

将 `内容` 交给 AI，提取并创建一条 DDL。正文最多200字，可包含标题、截止日期、提前提醒要求和是否到期通知；缺少标题时由 AI 生成，作业标题应体现课程。不会额外读取群上下文。

正文中的成员提及会附上昵称和 QQ，由 AI 结合语义决定通知对象。通知对象必须是当前群实际成员，不能包含机器人。

未指定提前提醒时，默认提前30分钟、3小时、12小时、1天、1天12小时。AI 默认追加到期提醒，明确要求“到期不要再提醒”时取消到期节点。

请求真正提交模型后先回复“已提交模型，正在处理，请稍候。”；提取或校验失败时不会创建任务。

## `/ddl add-strict` 命令

### `/ddl add-strict` - CHAT

**完整格式**：`/ddl add-strict "NAME" [YYYY-MM-DD HH:mm] [-30min,-3h]`

**所需权限组**：`ddl`

按明确给出的标题、截止时间和提前量创建一条 DDL，不调用 AI。

- `"NAME"`：必填标题，必须使用英文双引号，标题为1至200字。
- `YYYY-MM-DD HH:mm`：必填截止时间，可用方括号或双引号包裹；格式中的日期不是可省略参数。
- `-30min,-3h`：可选的提前量列表，以英文逗号分隔。支持 `d`、`h`、`min`、`m` 及 `-1d20h` 这样的组合；必须写负偏移。
- 不提供提前量时，默认提前30分钟、3小时、12小时、1天、1天12小时。提供列表时使用该列表，不额外加入默认提醒。
- 不自动追加到期通知；需要到期提醒时在列表中加入 `-0min`。

任务只通知本人，不接受指定其他通知对象。

时间按北京时间解释，截止时间必须在未来。每项任务为一次性提醒，最多20个提醒时间；已经过去的提醒节点忽略。保存成功后发送确认和当前会话的 DDL 卡片。定时提醒也发送红色图片卡片；群聊会同时 @ 通知对象。

```text
/ddl add-strict "提交物理作业" [2026-11-01 18:00] -1d,-3h,-30min,-0min
/ddl add-strict "提交报告" [2026-11-02 18:00] -1d20h,-30min
```

### `/ddl add-strict` - GROUP

**完整格式**：`/ddl add-strict "NAME" [YYYY-MM-DD HH:mm] [-30min,-3h][;@成员,@成员]`

**所需权限组**：`admin` 或 `group.ddl`

按明确给出的标题、截止时间和提前量创建一条 DDL，不调用 AI。

- `"NAME"`：必填标题，必须使用英文双引号，标题为1至200字。
- `YYYY-MM-DD HH:mm`：必填截止时间，可用方括号或双引号包裹；格式中的日期不是可省略参数。
- `-30min,-3h`：可选的提前量列表，以英文逗号分隔。支持 `d`、`h`、`min`、`m` 及 `-1d20h` 这样的组合；必须写负偏移。
- 不提供提前量时，默认提前30分钟、3小时、12小时、1天、1天12小时。提供列表时使用该列表，不额外加入默认提醒。
- 不自动追加到期通知；需要到期提醒时在列表中加入 `-0min`。
- `;@成员,@成员`：可选的通知对象列表，放在命令末尾；不指定时通知设置者。最多20人，必须是本群实际成员，不能包含机器人。

时间按北京时间解释，截止时间必须在未来。每项任务为一次性提醒，最多20个提醒时间；已经过去的提醒节点忽略。保存成功后发送确认和当前会话的 DDL 卡片。定时提醒也发送红色图片卡片；群聊会同时 @ 通知对象。

```text
/ddl add-strict "提交物理作业" [2026-11-01 18:00] -1d,-3h,-30min,-0min
/ddl add-strict "提交报告" [2026-11-02 18:00] -1d20h,-30min
```

## `/ddl defaulttime` 命令

### `/ddl defaulttime` - CHAT

**完整格式**：`/ddl defaulttime ["提示词"]`

**所需权限组**：`ddl`

查看或保存个人自动分析所用的默认提醒要求。

- 不带参数：查看本人当前默认提示词。
- `"提示词"`：保存一段提醒要求，最多1000字；使用英文双引号包裹含空格的内容。
- `""`：清除个人设置，恢复系统默认。

只影响之后通过[私聊自动分析](autoanalysis.md)新建的个人任务，不改变已有任务，也不影响 `/ddl add` 和 `/ddl add-strict`。

未设置或提示词无效时，系统默认在截止前3天、1天及当天安排合适的中午/傍晚提醒，并考虑提前6小时、3小时、30分钟、5分钟和到期；晚于截止或已经过去的节点忽略，最多20次。

```text
/ddl defaulttime
/ddl defaulttime "提前2天中午12点、提前1小时提醒"
/ddl defaulttime ""
```

## `/ddl list` 命令

### `/ddl list` - CHAT

**完整格式**：`/ddl list [页码]`

**所需权限组**：无；所有用户可用。

列出自己的个人会话中未取消、仍有通知对象且尚未截止的 DDL，按截止时间排序。

`页码` 从1开始，省略时为第1页，每页20项；超出范围会提示总页数。每项显示标题、会话、创建方式、设置者、通知对象、截止时间及各通知节点状态。通知节点状态可包括待发送、已发送、跳过、取消、失败和结果不确定。

不能指定其他用户或群；失去创建权限后，仍能查看、取消本人的已有通知。

只有有效任务进入列表；查看已知编号的历史任务使用 `/ddl show 编号`。

```text
/ddl list
/ddl list 2
```

### `/ddl list` - GROUP

**完整格式**：`/ddl list [页码]`

**所需权限组**：无；所有用户可用。

列出当前群中未取消、仍有通知对象且尚未截止的 DDL，按截止时间排序。

`页码` 从1开始，省略时为第1页，每页20项；超出范围会提示总页数。每项显示标题、会话、创建方式、设置者、通知对象、截止时间及各通知节点状态。通知节点状态可包括待发送、已发送、跳过、取消、失败和结果不确定。

必须是本群实际成员；不能借此指定其他群或个人会话。

只有有效任务进入列表；查看已知编号的历史任务使用 `/ddl show 编号`。

```text
/ddl list
/ddl list 2
```

## `/ddl view` 命令

### `/ddl view` - CHAT

**完整格式**：`/ddl view`

**所需权限组**：无；所有用户可用。

将自己的个人会话最近10个有效 DDL 渲染成一张时间卡片并发回当前会话，不调用 AI。任务按截止时间排列，已取消、全部退订或已过期的任务不进入卡片。

不接受页码、编号或目标会话参数。需要完整列表使用 `/ddl list`，查看具体通知状态使用 `/ddl show 编号`。

不能指定其他用户或群；失去创建权限后，仍能查看、取消本人的已有通知。

```text
/ddl view
```

### `/ddl view` - GROUP

**完整格式**：`/ddl view`

**所需权限组**：无；所有用户可用。

将当前群最近10个有效 DDL 渲染成一张时间卡片并发回当前会话，不调用 AI。任务按截止时间排列，已取消、全部退订或已过期的任务不进入卡片。

不接受页码、编号或目标会话参数。需要完整列表使用 `/ddl list`，查看具体通知状态使用 `/ddl show 编号`。

必须是本群实际成员；不能借此指定其他群或个人会话。

```text
/ddl view
```

## `/ddl show` 命令

### `/ddl show` - CHAT

**完整格式**：`/ddl show 编号`

**所需权限组**：无；所有用户可用。

查看自己的个人会话中 `编号` 对应的任务详情，包括标题、截止时间、设置者、通知对象和每个提醒节点的发送状态，也可查看已取消或已过期任务。

`编号` 必须为正整数，只在所属会话内有效；不同用户或群可以有相同编号。本会话不存在该编号时返回错误。

不能指定其他用户或群；失去创建权限后，仍能查看、取消本人的已有通知。

```text
/ddl show 3
```

### `/ddl show` - GROUP

**完整格式**：`/ddl show 编号`

查看当前群中 `编号` 对应的任务详情，包括标题、截止时间、设置者、通知对象和每个提醒节点的发送状态，也可查看已取消或已过期任务。

`编号` 必须为正整数，只在所属会话内有效；不同用户或群可以有相同编号。本会话不存在该编号时返回错误。

必须是本群实际成员；不能借此指定其他群或个人会话。

```text

```

## `/ddl remove` 命令

### `/ddl remove` - CHAT

**完整格式**：`/ddl remove 编号`

**所需权限组**：无；所有用户可用。

取消自己的个人会话中指定任务的通知，`编号` 是当前会话内的正整数编号。

- 设置者执行：取消整条任务的全部未发通知。
- 其他被通知者执行：仅移除自己，不影响其余通知对象。
- 既不是设置者也不是通知对象：拒绝操作。

保留任务编号及发送历史；没有剩余通知对象时，后续提醒不再发送。成功后自动刷新当前会话卡片。

不能指定其他用户或群；失去创建权限后，仍能查看、取消本人的已有通知。

```text
/ddl remove 3
```

### `/ddl remove` - GROUP

**完整格式**：`/ddl remove 编号`

**所需权限组**：无；所有用户可用。

取消当前群中指定任务的通知，`编号` 是当前会话内的正整数编号。

- 其他被通知者执行：仅移除自己，不影响其余通知对象。
- 既不是设置者也不是通知对象：拒绝操作。

保留任务编号及发送历史；没有剩余通知对象时，后续提醒不再发送。成功后自动刷新当前会话卡片。


## `/ddl clear` 命令

### `/ddl clear` - CHAT

**完整格式**：`/ddl clear [this|群号|all]`

**所需权限组**：`ddl`

批量取消指定范围内的任务及未发通知，保留历史记录和编号。

- 不带参数或使用 `this`：清空自己的个人任务。
- `群号`：清空指定群；跨群操作需要全局 `admin`。
- `all`：需要全局 `admin`，清空当前平台与机器人账号下的所有群任务，不清空任何个人任务。

成功后刷新当前会话卡片；群清除会通知受影响的通知对象。Readonly 群不处理 DDL 命令。

```text
/ddl clear
/ddl clear 3333
/ddl clear all
```

### `/ddl clear` - GROUP

**完整格式**：`/ddl clear [this|群号|all]`

**所需权限组**：`admin` 或 `group.admin`

批量取消指定范围内的任务及未发通知，保留历史记录和编号。

- 不带参数或使用 `this`：清空本群。只有 `group.admin` 时，显式群号也只能是本群。
- `群号`：清空指定群；跨群操作需要全局 `admin`。
- `all`：需要全局 `admin`，清空当前平台与机器人账号下的所有群任务，不清空任何个人任务。

成功后刷新当前会话卡片；群清除会通知受影响的通知对象。Readonly 群不处理 DDL 命令。

```text
/ddl clear
/ddl clear 3333
/ddl clear all
```
