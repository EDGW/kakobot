# DDL 命令组

[命令目录](README.md) · [Super 管理](super/README.md)

本组涉及以下身份组（不新增身份组）：

- `ddl`：个人创建、默认提醒及清空。
- `admin`：群创建、清空及跨群清空。
- `group.ddl`：当前群创建。
- `group.admin`：当前群清空，并继承 group.ddl。

## `/ddl add` 命令

### `/ddl add` - CHAT

**完整格式**：`/ddl add 内容`

**所需权限组**：`ddl`

正文最多200字，交给 AI 提取一条一次性 DDL，不读取额外群上下文。成功后发送确认与当前会话 DDL 卡片。个人任务只能通知自己。

### `/ddl add` - GROUP

**完整格式**：`/ddl add 内容`

**所需权限组**：`admin` 或 `group.ddl`

须先真实 @机器人。正文最多200字，交给 AI 提取一条一次性 DDL，不读取额外群上下文。成功后发送确认与当前会话 DDL 卡片。通知对象必须是当前群实际成员，不得包含机器人。

## `/ddl add-strict` 命令

### `/ddl add-strict` - CHAT

**完整格式**：`/ddl add-strict "NAME" [YYYY-MM-DD HH:mm] [-30min,-3h]`

**所需权限组**：`ddl`

直接解析标题、截止时间和提前量，不调用 AI。个人任务只能通知自己。

### `/ddl add-strict` - GROUP

**完整格式**：`/ddl add-strict "NAME" [YYYY-MM-DD HH:mm] [-30min,-3h][;@成员,@成员]`

**所需权限组**：`admin` 或 `group.ddl`

须先真实 @机器人。直接解析标题、截止时间和提前量，不调用 AI；群内可在末尾用 ;@成员,@成员 指定通知对象，不指定则通知设置者。通知对象必须是当前群实际成员，不得包含机器人。

## `/ddl defaulttime` 命令

### `/ddl defaulttime` - CHAT

**完整格式**：`/ddl defaulttime ["提示词"]`

**所需权限组**：`ddl`

不带参数查看个人自动分析默认提醒；传提示词保存，传空字符串恢复系统默认。仅影响之后自动识别的新任务。

## `/ddl clear` 命令

### `/ddl clear` - CHAT

**完整格式**：`/ddl clear [this|群号|all]`

**所需权限组**：`ddl`

清空指定范围的 DDL，保留历史及编号；群清空会通知受影响对象并刷新卡片。默认清空自己的个人任务；指定群号或 all 还需全局 `admin`，all 只清除群任务。

### `/ddl clear` - GROUP

**完整格式**：`/ddl clear [this|群号|all]`

**所需权限组**：`admin` 或 `group.admin`

须先真实 @机器人。清空指定范围的 DDL，保留历史及编号；群清空会通知受影响对象并刷新卡片。默认清空本群；`group.admin` 仅限本群，跨群及 all 需要全局 `admin`。

## 使用规则与示例

`add` 正文最多200字，由 AI 提取一条一次性 DDL。群内真实 @成员会附上其昵称和 QQ，让 AI 决定通知对象。没有名称时由 AI 生成，作业标题应体现课程。不会读取额外的群上下文。

`add-strict` 直接解析，不调用 AI。例如：

```text
/ddl add-strict "提交物理作业" [2026-11-01 18:00] -1d,-3h,-30min
```

群内可在末尾使用 `;@成员,@成员` 指定通知对象，不指定则通知设置者；私聊不能指定其他人。严格模式支持组合提前量，如 `-1d20h`。

未指定提前量时，手动创建默认提前30分钟、3小时、12小时、1天、1天12小时。AI 创建默认到期再提醒一次，除非明确要求不要；严格模式不自动追加到期通知，可用 `-0min` 明确设置。

所有时间按北京时间；任务不循环，每个提醒方案最多20个时间（含到期），过去的提醒时间忽略。成功创建后自动发送更新的 DDL 卡片。

编号在每个会话内独立。普通用户只能查看自己的个人任务或所在群的任务；失去创建权限后仍能查看、取消自己的已有通知。修改、取消成功后会刷新卡片，群清除会 @受影响的通知对象。Readonly 群不处理 DDL 命令，不向群发送提醒。

私聊默认提醒和直接消息识别详见 [自动分析](autoanalysis.md)。
