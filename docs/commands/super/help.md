# Super 帮助 命令组

[命令目录](../README.md) · [Super 目录](README.md)

本组涉及以下身份组（不新增身份组）：

- `super`：仅配置 super_user 指定。

仅配置项 `super_user` 指定的账号可使用；通用约定见 [Super 目录](README.md)。

## `/super` 命令

### `/super` - CHAT

**完整格式**：`/super`

**所需权限组**：`super`

Super 管理帮助。

### `/super` - GROUP

**完整格式**：`/super`

**所需权限组**：`super`

须先真实 @机器人。Super 管理帮助。

## `/super help` 命令

### `/super help` - CHAT

**完整格式**：`/super help [role|ddl|schedule|request|cost|announce|readonly]`

**所需权限组**：`super`

分类查看管理帮助。

### `/super help` - GROUP

**完整格式**：`/super help [role|ddl|schedule|request|cost|announce|readonly]`

**所需权限组**：`super`

须先真实 @机器人。分类查看管理帮助。

## 使用规则与示例

`/super` 与 `/super help` 查看全部管理帮助；`/super help role`、`/super help ddl`、`/super help schedule` 等查看分类。非 Super 的普通帮助不会展示这些入口。
