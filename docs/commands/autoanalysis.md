# 私聊自动分析 命令组

本组涉及以下身份组：

- `autoanalysis`：由 admin、super 继承获得，且配置需启用。

## 私聊消息自动识别

### 直接发送消息 - CHAT

**完整格式**：直接发送文字、引用或合并转发，不带命令前缀。

**所需权限组**：`autoanalysis`，且配置已启用该功能。

需要有效 `autoanalysis` 身份组且配置启用。直接私聊发送文字、引用或合并转发，即可识别个人 DDL；各次消息独立，不关联历史聊天。

- 支持最多4层嵌套合并转发，只从可直接读取的正文识别，不调用历史 `get_msg`。
- 相对日期参考可用的原消息时间，无原时间时用本次提交时间；忽略已过期 DDL。
- 向模型提供本人有效 DDL，重复录入会跳过并提示。
- 每包新增和修改合计最多10项；不会操作转发原作者或源群的任务。
- 修改任务不再要求 `#`：可以使用 `第N个任务`、任务标题或截止时间定位；“第几个任务”按截止时间升序计算。识别出修改意图后先展示待变更内容，回复“确认”才执行，回复“取消”放弃。
- 直接使用 `/ddl edit 内容` 也遵循先确认后执行；该入口只处理本人个人 DDL，不会误创建新任务。未带命令的自动分析仍不执行自然语言取消。
- 模型可能单独回复澄清问题；新增、修改和取消完成后会自动刷新卡片。

新任务的默认提醒使用本人的 [defaulttime 设置](ddl.md)；无个人设置时采用系统默认。默认提醒设置的查看、保存和重置说明见 `/ddl defaulttime`。

请求真正交给模型后，会先回复“已提交模型，正在处理，请稍候。”，再返回结果；没有调用模型时不发送此提示。

GROUP 不启用此入口；群内使用 [DDL 命令](ddl.md)。
