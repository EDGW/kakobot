# 群发送 命令组

[命令目录](README.md) · [Super 管理](super/README.md)

本组涉及以下身份组：

- `admin`：全局身份组。

## `/send` 命令

### `/send` - CHAT

**完整格式**：`/send GROUP 内容`

**所需权限组**：`admin`

将 `内容` 作为纯文本发送到明确指定的群，群号必须为正整数，内容不能为空；含空格的剩余内容作为同一段文字发送。

无论从私聊还是群聊发起，发送目标都由群号决定；不会把发起会话当作默认目标。成功后在发起会话回复发送确认。目标群为 Readonly 时拦截，Super 也不能绕过。

```text
/send 3333 明天18点前提交报告
```
