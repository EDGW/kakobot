# discuss 工具

全部工具初始关闭，必须同时通过系统总开关和群开关，并受每轮单工具及总工具执行次数限制。每次执行前重新检查最新权限、群配置和会话状态，失败执行仍占次数，执行前拦截不计。

| 工具 | 能力 |
| --- | --- |
| search_web | Tavily 搜索，最多返回 3 条来源和摘要；需系统搜索 Key |
| fetch_webpage | 读取公开 HTTP(S) 网页，用 trafilatura 提取正文 |
| query_group_data | 固定只读查询当前群的 DDL 数据，不能跨群或执行任意 SQL |
| read_session_history | 读取当前会话的归档片段，支持 offset；不提供其他会话、Key 或思考正文 |

搜索和网页读取分别授权。网页工具使用 safehttpx 验证并固定公开 IP，逐跳检查重定向，禁止本机、内网和云元数据地址，限制大小、时限和结果长度，不继承浏览器登录态。

工具结果仅作为不可信资料，不赋予任何额外权限。没有 shell、Python 执行、文件系统、电脑控制或任意 MCP 工具。

一次用户请求包含内部多轮模型调用，工具次数在整个请求内累计，不会每次调用模型就重置。外部搜索服务的费用与模型 tokens 分开，当前 token 预算不包含搜索服务收费。
