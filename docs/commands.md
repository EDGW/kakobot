# 普通命令

[返回 README](../README.md) · [Super 管理](super.md)

群聊中的所有命令均须真实 @机器人，文本里的“@机器人”不算。私聊直接输入。`/help [命令]` 根据当前身份组与会话位置显示可用用法，例如 `/help ddl`、`/help ddl add-strict`。

## 身份与广播偏好

- `/role`：查询本人全局身份组；私聊显示本人的全部群身份组，群聊只显示本群，包含继承来源。
- `/announce-reject on|off`：拒收或恢复本机器人的广播，群聊中也可设置本人的偏好，不影响 DDL 提醒。

全局权限继承：`super → admin → autoanalysis → ddl、summary`；群内：`group.admin → group.ddl、group.summary`。群组按群隔离，与 QQ 原生管理员无关。

## 创建 DDL

| 命令 | 私聊要求 | 群聊要求 |
| --- | --- | --- |
| `/ddl add 内容` | ddl | admin 或 group.ddl |
| `/ddl add-strict "名称" [YYYY-MM-DD HH:mm] [-30min,-3h][;@成员,@成员]` | ddl，仅通知自己 | admin 或 group.ddl |

`add` 正文最多200字，由 AI 提取一条一次性 DDL。群内真实 @成员会附上其昵称和 QQ，让 AI 决定通知对象。没有名称时由 AI 生成，作业标题应体现课程。不会读取额外的群上下文。

`add-strict` 直接解析，不调用 AI。例如：

```text
/ddl add-strict "提交物理作业" [2026-11-01 18:00] -1d,-3h,-30min
```

群内可在末尾使用 `;@成员,@成员` 指定通知对象，不指定则通知设置者；私聊不能指定其他人。严格模式支持组合提前量，如 `-1d20h`。

未指定提前量时，手动创建默认提前30分钟、3小时、12小时、1天、1天12小时。AI 创建默认到期再提醒一次，除非明确要求不要；严格模式不自动追加到期通知，可用 `-0min` 明确设置。

所有时间按北京时间；任务不循环，每个提醒方案最多20个时间（含到期），过去的提醒时间忽略。成功创建后自动发送更新的 DDL 卡片。

## 查看与取消

| 命令 | 行为 |
| --- | --- |
| `/ddl list [页码]` | 详细列表，每页20项，包含截止、通知对象与通知状态 |
| `/ddl show 编号` | 查看指定任务详情 |
| `/ddl view` | 直接发送最近10个有效任务的时间卡片；不调用 AI |
| `/ddl remove 编号` | 设置者取消整条任务；被通知者只退出自己的通知 |
| `/ddl clear [this]` | 清空自己的个人 DDL（ddl）或本群任务（admin/group.admin） |
| `/ddl clear 群号` | 全局 admin 可跨群清除；group.admin 仅限本群 |
| `/ddl clear all` | 全局 admin 清除当前机器人下全部群任务，不清除个人任务 |

编号在每个会话内独立。普通用户只能查看自己的个人任务或所在群的任务；失去创建权限后仍能查看、取消自己的已有通知。修改、取消成功后会刷新卡片，群清除会 @受影响的通知对象。Readonly 群不处理 DDL 命令，不向群发送提醒。

## 私聊自动分析

需要有效 `autoanalysis` 身份组且配置启用。直接私聊发送文字、引用或合并转发，即可识别个人 DDL；各次消息独立，不关联历史聊天。

- 支持最多4层嵌套合并转发，只从可直接读取的正文识别，不调用历史 `get_msg`。
- 相对日期参考可用的原消息时间，无原时间时用本次提交时间；忽略已过期 DDL。
- 向模型提供本人有效 DDL，重复录入会跳过并提示。
- 每包新增和修改合计最多10项；不会操作转发原作者或源群的任务。
- 修改时明确编号和字段，例如“把 DDL #3 的提醒改为提前3小时和30分钟”。支持标题、截止、提醒和到期通知。自然语言取消尚不支持，请用 `/ddl remove 编号`。
- 模型可能单独回复澄清问题；新增、修改和取消完成后会自动刷新卡片。

通过 `/ddl defaulttime "提前2天中午12点、提前1小时提醒"` 保存个人默认提醒，`/ddl defaulttime` 查看，`/ddl defaulttime ""` 恢复默认。仅影响之后自动识别的新任务，不影响手动创建和已有任务。

未设置或提示词无效时，默认安排截止前3天、1天及当天的合适中午/傍晚时间，以及提前6小时、3小时、30分钟、5分钟和到期。晚于截止或已经过去的节点忽略，最多20次。

请求真正交给模型后，会先回复“已提交模型，正在处理，请稍候。”，再返回结果；没有调用模型时不发送此提示。

## 聊天总结与群发送

| 命令 | 要求与范围 |
| --- | --- |
| `/summary`，附带或引用文字/聊天记录 | 私聊 summary；仅总结本次内容 |
| `/summary text 内容` | 私聊 summary；总结文字 |
| `/summary group 群号` 或 `/summary 群号` | 私聊 summary；非 admin 须在目标群 |
| `/summary` | 群内 admin 或 group.summary；总结本群最近可获取消息 |
| `/summary 群号` | 群内全局 admin；可指定其他群 |
| `/send 群号 内容` | 全局 admin；发送纯文本，Readonly 仍拦截 |
| `/readonly list` | 私聊全局 admin；查看只读群 |

群历史最多读取接口可获取的100条，不能保证获得全部历史或 QQ 未读状态。总结末行显示 `（+xxxx tokens used)`，未返回有效用量则显示未知。

超过15行的文本会放进合并聊天记录，图片直接发送。群内真实 @机器人并只说“你好”时，回复“好牛魔呢”。
