kakobot已更新到v1.3.1版本。

/help 和 /super help 现在以图片展示帮助：/help ddl 查看DDL用法，/super help announce 查看广播管理。直接使用 /help 或 /super help 可查看各自的功能目录；不再支持在帮助命令后继续追加子命令。

所有用户都可以使用 /version 查看当前安装版本，使用 /changelog 查看完整更新日志。Super 可使用 /super schedule 查看全部待发提醒，或加 user QQ号、group 群号筛选。

您可以直接私聊设置或调整个人DDL；调整时请给出具体编号和修改要求。取消请使用 /ddl remove 编号。多条消息不会自动关联，需要时请使用可读取的引用或合并转发。
